# TP2 – Développement d’Applications Réparties (DAR2025)

Ce dépôt contient les deux activités du **TP2** portant sur les **sockets TCP** en Java, avec l’échange de chaînes de caractères et d’objets.

## Structure du dépôt
- **Activité 2-1** : Échange de chaînes de caractères (CC) entre un client et un serveur via les sockets TCP. 
- **Activité 2-2** : Échange d’objets entre un client et un serveur via les sockets TCP.  

## Contenu de chaque activité
Chaque branche contient :
- le **code source** (`src/`)
- un fichier **README.md** décrivant brièvement l’activité
- le **rapport Word** demandé
